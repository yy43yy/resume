# Yi Yang — personal portfolio

A responsive, static portfolio built with HTML, CSS, and JavaScript. No build step or external assets are required.

## Preview

Open `index.html` directly, or serve this folder with any static web server. For example, `python -m http.server 4173`, then visit `http://localhost:4173`.

## Update

- `index.html`: biography, experience, projects, skills, and contact links.
- `style.css`: page layout, responsive rules, light and dark palettes, and project illustrations.
- `script.js`: theme preference, photo selection, project filters, and copying the email address.
- `yi-yang-resume.pdf`: current résumé download, copied from the newly supplied résumé. The previous `yy resume final.pdf` is preserved.
- `assets/`: original personal photos and the new favicon.

Project artwork is illustrative and labelled accordingly. Replace it with real screenshots when available. Project-specific repository and demo links have deliberately been omitted because none were supplied; the GitHub link opens the verified profile URL from the original site.

The main content and project disclosures remain usable without JavaScript. Theme preference follows the operating system until a visitor chooses an override. Motion respects the visitor’s reduced-motion setting.

## Hosting

Upload the complete folder to a static host, keeping relative paths intact. This update does not change hosting settings or publish the site.
